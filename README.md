# لیوشا

پروتوتایپ تعاملی و راست‌چین لیوشا (Liosha): یک میز کار برای ساخت گام‌به‌گام کسب‌وکار، برنامه‌ریزی سوشال، آموزش فروش، پشتیبانی دوگانه و ویترین تبلیغاتی.

نسخهٔ عمومی: [https://shakibamontazer.github.io/liosha/](https://shakibamontazer.github.io/liosha/)

همه داده‌ها آزمایشی هستند و در مرورگر ذخیره می‌شوند. پرداخت، تولید ویدیو و احراز هویت شبیه‌سازی شده‌اند.

## اجرا

```bash
npm install
npm run dev
```

سپس [http://127.0.0.1:43123](http://127.0.0.1:43123) را باز کنید. صفحه اول لندینگ است: نام، نام خانوادگی، موبایل و کد اختصاصی، بعد سه سؤال. میز کار بعد از پاسخ باز می‌شود.

کاربر آزمایشی «نیکا رضایی» با پلن محبوب، ۳٬۲۰۰ توکن و دو پروژه («آتلیه نور» و «کافه متن») وارد می‌شود. از منو می‌توان داده‌ها را بازنشانی کرد.

## چه چیزهایی کار می‌کند

- خانه، استوری تمام‌صفحه، منوی کناری و نوار پایین
- بیزنس‌ساز یازده‌مرحله‌ای با درس، فرم و خروجی هوش مصنوعی
- سوشال مدیا: دوازده پلتفرم و استودیوی تقویم، ویدیو، تصویر و صدا
- دوره‌های فروش و بازاریابی با پروژه عملی
- کارت «طراحی سایت» برای فاز بعد
- پرس‌وجو با برچسب و پاسخ برگزیده
- بیزنس من: بنر، پیش‌نیاز، پیش‌نمایش و تأیید آزمایشی
- اشتراک سه‌سطحی و گردش توکن
- پشتیبانی هوش مصنوعی و منتور انسانی (تیکت، گفتگو، تماس، تایمر زیر دو ساعت)
- روشن/تیره، فارسی/انگلیسی، و مانیفست PWA

## ساخت نسخه تولید

```bash
npm run build
npm start
```

سرویس‌ورکر فقط در نسخه تولید ثبت می‌شود.
